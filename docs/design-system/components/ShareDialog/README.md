# ShareDialog

The share dialog lists a board's shares and adds new ones; owner only.

- Each share: display name, email, role select (Observer, Editor), "Remove".
- The search input lists up to 10 matching users from 3 characters; picking one grants Observer at once, no invitation.
- Role changes apply on the member's next request.
- Members who are not the owner see "Leave board" on the board page instead.

Consumer provides: current shares and the user search results.
