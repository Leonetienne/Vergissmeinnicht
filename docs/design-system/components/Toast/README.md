# Toast

Toasts show transient messages and errors in the bottom-right corner.

- Status on `inverse`, errors on `danger` (`vm-toast--error`).
- Close after 5 seconds or by "×"; newest at the bottom.
- Text says what happened in a few words: "Task deleted", "Undo: rename list", "Board not found".

Consumer provides: the message and whether it is an error.
