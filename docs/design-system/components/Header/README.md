# Header

The header tops every logged-in page: app name, search button, theme menu, menu.

- The app name links to the board list.
- The search button opens the search popup, same as Ctrl+F or Cmd+F.
- The theme menu holds a segmented "Light", "Dark", "System" switch and the colour themes as radio items, each with a swatch (`accent` dot on `accent-soft`) drawn in its own theme. A pick applies at once.
- The menu holds "Settings" and "Logout".
- Painted with `surface` at the user's UI opacity, `border` hairline below.
